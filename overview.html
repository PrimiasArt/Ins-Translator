💻 Hướng Dẫn Chạy & Build Trên Máy Khác

  1. Yêu cầu hệ thống: Android Studio Jellyfish / Iguana trở lên, JDK 17, Android SDK 34.
  2. Mở dự án: Giải nén file ZIP dự án vào thư mục làm việc, sau đó mở Android Studio và chọn Open an existing Android Studio project trỏ tới thư mục dự án.
  3. Build APK Debug: Mở Terminal trong Android Studio và chạy lệnh:
    gradlew :app:assembleDebug (trên Windows) hoặc ./gradlew :app:assembleDebug (trên macOS/Linux).
  4. Cấu hình Gemini API Key: Mở ứng dụng trên điện thoại/giả lập, vào tab Cài đặt (Settings), dán Gemini API Key của bạn và bấm Load Models để bắt đầu sử dụng đầy đủ tính năng AI.
